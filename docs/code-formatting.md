# Code Formatting Guidelines

[← Back to Home](../README.md)

## Function documentation

All functions should include:

- Name
- Description
- Contributors

## Git commit-message format

```text
<type>(<scope>): <short description>
```

- **type** — what kind of change was made
- **scope** — where in the codebase the change applies, such as a region or milestone
- **description** — present tense, no period, and about 50 characters where practical

### Examples

```text
FEAT(<scope>): added a NEW feature to the function
FIX(<scope>): fixed an EXISTING feature in the function
PERF(<scope>): optimized an EXISTING feature in the function
COMM/STYLE(<scope>): added COMMENTS to the function
```
